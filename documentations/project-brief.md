# Project Brief --- Personal Todo App

## 1. Project Overview

We are building a personal Todo application to help one person organize,
manage, and keep track of their own tasks.

The application will let the user create tasks with useful details,
organize them by deadline and priority, update task information when
plans change, and keep notes attached to each task.

## 2. Why We Are Building It

The goal is to have one simple place to:

-   Record tasks instead of relying on memory.
-   Keep useful details and notes alongside each task.
-   Understand which tasks are urgent or important.
-   Review and update tasks as plans change.
-   Keep track of task progress.

This is a personal application for the developer's own everyday use. The
first version should focus on the core task-management experience rather
than unnecessary features.

## 3. Who Will Use It?

The initial version is designed for one user: the person building and
using the application.

## 4. Main Goal

Build a straightforward, reliable Todo app that makes it easy to add,
organize, review, and update personal tasks.

## 5. What the First Version Includes

-   Create a task with a name, description, deadline, and priority.
-   Add notes to a task.
-   Update a task's information, deadline, or priority.
-   Organize and view tasks according to deadline and priority.
-   Mark a task as read, as specified in the initial feature
    requirements.

## 6. What We Are Not Building Yet

The first version will not include features such as team collaboration,
multiple user accounts, calendar integrations, reminders, or advanced
productivity analytics. These can be considered later if they become
useful.

## 7. How We Will Know It Is Useful

The first version will be useful when the user can comfortably add
tasks, find them by deadline or priority, keep notes, make updates, and
maintain an accurate task list during everyday use.
